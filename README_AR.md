# مطاعم الشيباني — مشروع معاينة مع إعداد بناء APK

## ماذا يوجد في هذا الملف؟
- `www/`: صفحات HTML النشطة: الرئيسية، تفاصيل الطبق، السلة، وحالة الطلب.
- `package.json` و`capacitor.config.json`: إعداد أولي لتغليف صفحات الويب كتطبيق Android باستخدام Capacitor.
- `.github/workflows/build-apk.yml`: سير عمل يبني APK تجريبيًا على GitHub Actions عند رفع التغييرات إلى `main` أو تشغيله يدويًا.

## بناء APK من الهاتف باستخدام GitHub (خطوات للمبتدئ)
1. أنشئ حسابًا على GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا (Repository). المستودع العام أسهل للتجربة، لكن تذكر أن الملفات ستكون عامة؛ لا ترفع بيانات سرية أو مفاتيح توقيع.
3. فك ضغط هذا الملف على جهازك أو استخدم مدير ملفات يدعم فك ZIP.
4. ارفع **محتويات المجلد** إلى المستودع مع الحفاظ على المسارات، خصوصًا `.github/workflows/build-apk.yml` و`www/`. إذا لم يظهر مجلد `.github` في مدير الملفات، فعّل إظهار الملفات المخفية أو أنشئ الملفات من واجهة GitHub.
5. تأكد أن الفرع اسمه `main` ثم افتح تبويب **Actions** في المستودع.
6. افتح سير العمل **Build Android APK** واضغط **Run workflow**. يمكن أيضًا أن يبدأ تلقائيًا بعد رفع الملفات إلى `main`.
7. بعد نجاح البناء، افتح تشغيل سير العمل الناجح، وانتقل إلى **Artifacts**، ثم نزّل `alshaibany-debug-apk`.
8. فك ضغط ملف Artifact، ثم افتح `app-debug.apk` على هاتف Android وثبّته. قد تحتاج إلى السماح بالتثبيت من هذا المصدر في إعدادات Android.

## ملاحظات مهمة
- هذا مسار بناء تجريبي؛ لم يُنفّذ البناء فعليًا داخل هذه الحزمة، لذلك يجب انتظار نتيجة GitHub Actions والتعامل مع أي خطأ بناء يظهر.
- يتطلب Capacitor 8 بيئة Node.js 22 أو أحدث، وAndroid SDK لبناء Android؛ يوفر سير العمل بيئة Linux للبناء بدلًا من الحاجة إلى تثبيت Android Studio على الهاتف. المراجع الرسمية: https://capacitorjs.com/docs/getting-started/environment-setup وhttps://capacitorjs.com/docs/getting-started
- الناتج APK تجريبي (debug) للتثبيت والاختبار، وليس إصدارًا موقّعًا للنشر التجاري.
- لا توجد قاعدة بيانات أو API أو نظام فعلي لاستقبال الطلبات أو الدفع أو تتبع السائق. تأكيد الطلب يعرض تنبيهًا تجريبيًا فقط.
- أسماء الفروع والأسعار ورسوم التوصيل وطرق الدفع تحتاج إلى تأكيد الإدارة قبل أي استخدام حقيقي.
- يعتمد بعض التنسيق والصور والخطوط على الإنترنت لأن الصفحات الأصلية تستخدم CDN وروابط صور خارجية.
